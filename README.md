# RHEL Secure File Server

A hands-on Linux System Administration project focused on
building a secure network file server using Red Hat
Enterprise Linux (RHEL).

## Project Objective

Build a secure RHEL-based file server using:

- LVM for flexible storage management
- NFS for network file sharing
- firewalld for network access control
- SELinux for mandatory access control
- SSH key-based authentication for secure remote access

## Technologies Used

- LVM
